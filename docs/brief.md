# Brief — ฟ้าใส ทันตกรรม (Fah Sai Dental)

ร่างวันที่ 25 ต.ค. 2569 · ส่งงานภายใน 7 พ.ย. 2569 (Fastwork เปิด 14 พ.ย.)

## งาน

- **คืออะไร:** ชิ้นพอร์ตของ PanuWeb บน Fastwork เป็นตัวอย่าง service "ระบบจองคิว / นัดหมาย" แพ็ก Premium 45,900 บาท คลินิกสมมติ เครดิตท้ายเว็บเขียนว่าเป็นเดโม
- **คนอ่าน:** (1) คนที่จะจ้างทำเว็บ เปิดจากพอร์ต Fastwork ต้องเห็นว่าระบบจองใช้ได้จริงทั้งฝั่งคนไข้และฝั่งเจ้าของ (2) ในเรื่องเล่าของเว็บ: คนทำงาน/ครอบครัวย่านลาดพร้าว–โชคชัย 4 ที่อยากจองหมอฟันโดยไม่ต้องโทร
- **ภาษา:** ไทยทั้งเว็บ ชื่ออังกฤษ "Fah Sai Dental" ใช้แค่ในโลโก้รอง/อีเมล/ภาพแชร์
- **ฟอนต์:** Anuphan (หัวข้อ) + IBM Plex Sans Thai Looped (เนื้อหา) — ตัวเลขเวลา/ราคาใช้ Anuphan tabular
- **โทน:** สว่าง ขาว + ฟ้าอ่อน มีมิ้นต์เป็นสีรอง (ชื่อคลินิกพาไปทางฟ้า)
- **หน้าและ section (ตามลำดับ):**
  1. Hero
  2. บริการและราคา (ขูดหินปูน, อุดฟัน, ถอนฟัน, รักษารากฟัน, ฟอกสีฟัน, จัดฟัน-ปรึกษา, รากเทียม-ปรึกษา) พร้อมระยะเวลาต่อบริการ
  3. ทีมหมอ 3–4 คน แต่ละคนมีวันเข้าคลินิก + บริการที่ทำ
  4. จองคิว (flow เต็ม): บริการ → หมอ → วันเวลาว่างจริง → ชื่อ/เบอร์ → มัดจำ PromptPay QR + แนบสลิป → หน้ารอยืนยัน
  5. มาครั้งแรก ไม่ต้องกลัว (ขั้นตอนตั้งแต่ถึงคลินิกจนกลับ)
  6. แผนที่ + เวลาทำการ + เดินจาก MRT โชคชัย 4
  7. Footer + เครดิตเดโม
  - `/owner` หลังบ้าน: ตารางรายวันแยกหมอ, รายการรอยืนยันพร้อมสลิป (ยืนยัน/ปฏิเสธ), สรุปรายเดือน
  - `/booking/[id]` หน้าสถานะการจองของคนไข้
  - loader, 404, favicon, ภาพแชร์ลิงก์
- **ภาพปกพอร์ต:** วางทั้งหน้าเป็นภาพยาวภาพเดียว ทั้งเว็บสว่าง จึงสลับจังหวะด้วย section ฟ้าเข้ม 1–2 ช่วง (จองคิว / footer) ให้ภาพย่ออ่านออก ทำโหมด `?capture` ตั้งแต่แรก

## ของจริง

- **รูป:** gen ด้วย Gemini ชุดเดียว (คลินิก, หมอ 3–4 คน, ห้องทำฟัน, เคาน์เตอร์) เขียน prompt ให้ไป gen ไฟล์ขนาดเต็ม ระบุในเครดิต
- **ทำเล:** ตึกแถวริมถนนลาดพร้าว ใกล้ปากซอยโชคชัย 4 เดินจาก MRT สายสีเหลือง สถานีโชคชัย 4 — พิกัดและเส้นทางดึงจาก OpenStreetMap ด้วย `scripts/build-map.mjs` (เครดิต © OpenStreetMap contributors)
- **ตัวเลข:** ราคาแบบคลินิกเอกชนย่านนี้ เช่น ขูดหินปูน 900, อุดฟัน 1,200–1,800 มัดจำ 300 บาท เปิด 10:00–20:00 หยุดวันพุธ (ปรับได้)
- **ไม่ได้ทำจริง:** PromptPay QR เป็นเลขสมมติ ไม่มีการตรวจสลิปอัตโนมัติ ไม่มีเงินเข้าจริง เขียนบอกบนหน้าจ่ายมัดจำ
- **ส่วนที่ใช้งานได้:** Supabase (ตาราง bookings, staff, schedules + Storage เก็บสลิป, กันจองซ้อนด้วย exclusion constraint/ล็อกในฐานข้อมูล) + Resend
  - เดโมสาธารณะ: ไม่ส่งอีเมลจริง (แสดงอีเมลบนเว็บแทน), `/owner` เข้าได้ไม่ต้องใช้รหัส, ข้อมูลรีเซ็ตทุกคืนด้วย Vercel Cron เป็นชุดสมมติใหม่, จำกัดครั้งต่อ IP (`x-vercel-forwarded-for`) + เพดานรวม
  - เครื่อง dev ไม่มีคีย์: เก็บลงไฟล์ local, อีเมลลงโฟลเดอร์ outbox
  - "วันนี้" = เวลา Bangkok ทั้ง server และ browser (ใช้ `src/lib/days.ts` จากปักษ์)

## ไอเดีย (ร่าง — รอเลือก)

- **Signature idea:** ไปหาหมอฟันแบบใจฟ้าใส — วันหนึ่งของคลินิกตั้งแต่ 10:00 ถึง 20:00 คือท้องฟ้าหนึ่งวัน เวลานัดทุกช่องมีสีฟ้าของชั่วโมงนั้น และเมฆคือความกังวลที่ค่อยๆ หายไประหว่างทางจอง
- **ของที่วนกลับมา:** เมฆก้อนเล็กทรงฟันกราม (ฟันกรามด้านบนโค้งเหมือนก้อนเมฆ) — ใน loader, favicon, หมุดแผนที่, ช่องเวลาที่เต็ม, หน้า 404 ("เมฆบังหน้านี้")
- **ทิศทางที่จะทำให้ดู (2–3 แบบพร้อมกัน):**
  - **A · ปัดเมฆ** — hero เต็มไปด้วยเมฆ นิ้ว/เมาส์ปัดเมฆออก เห็นฟ้าใสและ "คิวว่างวันนี้" ที่ซ่อนอยู่ข้างหลัง ปล่อยไว้เมฆลอยกลับมาช้าๆ (เสี่ยงคล้ายกระจกฝ้าของรอนเย็น ต้องทำให้ต่าง)
  - **B · ฟ้าทั้งวัน** — hero คือแถบเวลา 10:00–20:00 ลากเมาส์/นิ้วไปตามแนวนอน สีฟ้าเปลี่ยนตามชั่วโมง ช่องที่ว่างจริงของหมอแต่ละคนโผล่เป็นช่องฟ้าใส ช่องที่เต็มเป็นเมฆ กดช่องไหนก็ข้ามไปฟอร์มจองพร้อมเวลานั้น — hero คือตัวระบบจองเลย
  - **C · 32 ซี่ (เกินไปโดยตั้งใจ)** — โค้งฟัน 32 ซี่ใหญ่เต็มจอ ซี่ฟันเอียงตามเมาส์เหมือนคลื่น แตะซี่ไหนบอกบริการที่เกี่ยวกับซี่นั้น scroll แล้วโค้งฟันคลี่เป็นเมนูบริการ

## จังหวะ (ร่าง)

- **Hero interaction:** ตามทิศทางที่เลือก (ทุกแบบมีท่าทางเองตอนไม่มีใครแตะ)
- **Scroll:** Lenis + GSAP ScrollTrigger
  - บริการ: reveal ทีละแถว (fade อยู่บนลูก ไม่ใช่แถว — บทเรียนปักษ์)
  - ทีมหมอ: pin แล้วเลื่อนแนวนอน ตารางสัปดาห์ของหมอแต่ละคนสว่างขึ้นตามคนที่อยู่ตรงกลาง
  - จองคิว: ไม่มี motion ระหว่างกรอก (ฟอร์มต้องนิ่ง)
  - มาครั้งแรก: scrub เมฆค่อยๆ หายตามขั้นตอน
  - แผนที่: scrub วาดเส้นทางเดินจาก MRT
- **Layout break:** section "มาครั้งแรก" — ขั้นตอนวางเป็นคอลัมน์เยื้อง ตัวเลขเวลาใหญ่วิ่งทับรูป
- **Loader / 404 / icon:** เมฆฟันกรามลอยออกจนฟ้าใส (นับตามของที่โหลดจริง), 404 เมฆบัง, favicon เมฆฟันกรามสีฟ้า
